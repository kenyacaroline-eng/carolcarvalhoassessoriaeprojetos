# Carol Carvalho Assessoria e Projetos

Website profissional de Carol Carvalho Assessoria e Projetos, apresentando serviços, portfólio de casos de sucesso, FAQ interativa e formulário de contato.

## 🎯 Sobre

Carol Carvalho Assessoria e Projetos é especializada em:
- Tráfego Pago (Meta Ads e Google Ads)
- Sites & Landing Pages
- GA4 & Rastreamento
- SEO Local & GMN
- Relatórios de Performance

## 🚀 Funcionalidades

### ✨ Seções Principais
- **Header Luxuoso**: Navegação fixa com menu interativo
- **Hero Section**: Apresentação com CTA principal
- **Serviços**: 6 serviços com modal interativo "Saiba Mais"
- **Portfólio**: Painel visual com prévia do site da Val Freire Estética, link para o projeto Seis na Estrada e acesso aos detalhes dos cases de sucesso
- **FAQ**: Accordion interativo com 6 perguntas frequentes
- **Contato**: Formulário e links diretos para WhatsApp/Instagram
- **Botão Flutuante**: WhatsApp fixo para facilitar contato

### 🎨 Design
- Design moderno e sofisticado com paleta nude, marrom e branco
- Responsivo (mobile, tablet, desktop)
- Animações suaves e transições elegantes
- Fontes premium (Playfair Display e Inter)

## 🚀 Como Usar

1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario/engajec-assessoria.git
cd engajec-assessoria
```

2. Abra o arquivo `index.html` no navegador ou use um servidor local:
```bash
# Python 3
python -m http.server 8000

# Node.js (com http-server)
npx http-server
```

3. Acesse: `http://localhost:8000`
